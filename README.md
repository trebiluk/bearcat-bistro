# Bearcat Bistro

Solvay UFSD lunch planner for SES, SMS, and SHS — 2026–27 menus, one-page flyers, family HTML, CEP free meals.

Live door: [The Tech Room](https://apps.kulibert.net/bistro) · source deploys as **bearcat-bistro**.

Wordmark only (no mascot). Gold fields are editable. USDA NDS is unedited.

## Local

```
npm install
npm run dev
```
